*# 1. Purpose*



*This document defines the official Context Prioritization strategy governing the Francisco Sánchez Portfolio AI-First engineering ecosystem.*



*Context Prioritization establishes how engineering context shall be ranked, selected, and loaded to maximize reasoning quality while minimizing unnecessary context consumption.*



*Only the most relevant validated context shall participate in engineering reasoning.*



*---*



*# 2. Objectives*



*The Context Prioritization process aims to:*



*- Maximize reasoning accuracy.*

*- Reduce context overload.*

*- Improve AI efficiency.*

*- Optimize context retrieval.*

*- Minimize irrelevant information.*

*- Preserve governance precedence.*

*- Improve repository consistency.*

*- Support scalable engineering.*



*---*



*# 3. Prioritization Philosophy*



*Not all context has equal importance.*



*Engineering reasoning shall consume the smallest amount of context capable of producing the correct decision.*



*Context relevance is more important than context volume.*



*---*



*# 4. Scope*



*Context Prioritization applies to:*



*- AI agents.*

*- Engineering workflows.*

*- Repository searches.*

*- AI prompts.*

*- Automation systems.*

*- Governance processes.*

*- Documentation retrieval.*

*- Engineering assistants.*



*---*



*# 5. Prioritization Principles*



*Context prioritization shall be:*



*- Deterministic.*

*- Explainable.*

*- Traceable.*

*- Governed.*

*- Hierarchical.*

*- Dynamic.*

*- Evidence-based.*



*---*



*# 6. Priority Hierarchy*



*The default context priority order is:*



*1. Governance*

*2. Engineering Standards*

*3. Architecture*

*4. ADRs*

*5. Active Project Context*

*6. Repository Documentation*

*7. Workflows*

*8. Templates*

*9. Quality Documentation*

*10. Knowledge Base*

*11. Operational Metrics*

*12. AI Memory*

*13. Historical Context*

*14. Session Context*



*Higher-priority artifacts shall always be evaluated first.*



*---*



*# 7. Relevance Evaluation*



*Context relevance shall consider:*



*- Task applicability.*

*- Engineering domain.*

*- Repository location.*

*- Lifecycle state.*

*- Version.*

*- Governance authority.*

*- Recent updates.*

*- Dependency relationships.*



*Only relevant context shall be loaded.*



*---*



*# 8. Context Weighting*



*Every context artifact may receive a dynamic priority score based on:*



*- Authority*

*- Freshness*

*- Relevance*

*- Traceability*

*- Relationship density*

*- Engineering impact*

*- Validation status*



*Weighting algorithms shall remain deterministic.*



*---*



*# 9. Mandatory Context*



*Certain context categories shall always be loaded:*



*- Active Governance*

*- Active Engineering Standards*

*- Applicable Architecture*

*- Applicable ADRs*



*Mandatory context cannot be skipped.*



*---*



*# 10. Optional Context*



*Optional context includes:*



*- Historical decisions.*

*- Metrics.*

*- Lessons Learned.*

*- Previous sessions.*

*- AI Memory.*

*- Archived documentation.*



*Optional context shall be loaded only when relevant.*



*---*



*# 11. Context Budget*



*Every execution shall operate within an appropriate context budget.*



*Priority shall be given to:*



*- Higher authority.*

*- Higher relevance.*

*- Lower redundancy.*



*Context budget optimization shall never compromise correctness.*



*---*



*# 12. Dynamic Prioritization*



*Priority may change based on:*



*- Repository changes.*

*- Task type.*

*- Engineering domain.*

*- Active workflow.*

*- Architecture evolution.*

*- Governance updates.*



*Prioritization shall adapt continuously.*



*---*



*# 13. Conflict Prioritization*



*When conflicting artifacts exist:*



*1. Governance prevails.*

*2. Higher lifecycle state prevails.*

*3. Latest approved version prevails.*

*4. Human review resolves remaining ambiguity.*



*Priority shall never override governance.*



*---*



*# 14. AI Integration*



*AI systems shall:*



*- Calculate context priority.*

*- Explain prioritization.*

*- Minimize unnecessary retrieval.*

*- Recommend additional context only when justified.*

*- Respect governance precedence.*



*AI prioritization shall remain transparent.*



*---*



*# 15. Performance Optimization*



*Prioritization shall improve:*



*- Retrieval latency.*

*- Token efficiency.*

*- AI inference speed.*

*- Repository search performance.*

*- Context quality.*



*Optimization shall never reduce engineering correctness.*



*---*



*# 16. Monitoring*



*Recommended metrics include:*



*- Average Context Size*

*- Retrieval Efficiency*

*- Context Relevance Score*

*- Priority Accuracy*

*- Context Budget Utilization*

*- Redundant Context Rate*



*These metrics support continuous optimization.*



*---*



*# 17. AI Operational Contract*



*## Responsibilities*



*AI systems shall:*



*- Prioritize context objectively.*

*- Respect governance hierarchy.*

*- Explain prioritization decisions.*

*- Optimize context loading.*

*- Detect missing high-priority artifacts.*



*---*



*## Authorized Actions*



*AI may:*



*- Rank context.*

*- Recommend retrieval order.*

*- Exclude irrelevant artifacts.*

*- Produce prioritization reports.*

*- Detect redundant context.*



*---*



*## Restricted Actions*



*AI shall not:*



*- Ignore mandatory context.*

*- Override governance priority.*

*- Hide prioritization decisions.*

*- Load deprecated artifacts preferentially.*

*- Optimize for speed at the expense of correctness.*



*---*



*## Success Criteria*



*The Context Prioritization process is successful when:*



*- AI consistently loads the most relevant context.*

*- Context size decreases without reducing quality.*

*- Repository searches become faster.*

*- Engineering reasoning improves.*

*- Governance remains authoritative.*



*---*



*## Failure Conditions*



*The Context Prioritization process fails when:*



*- Critical context is omitted.*

*- Low-priority context dominates reasoning.*

*- Context overload becomes common.*

*- AI ignores governance hierarchy.*

*- Prioritization becomes inconsistent.*



*---*



*## Escalation*



*Critical prioritization failures affecting governance, architecture, AI reasoning quality, repository integrity, or engineering decision-making shall require immediate review by the Project Owner.*



*---*



*# 18. Governance*



*The Context Prioritization strategy governs every mechanism responsible for ranking, selecting, optimizing, and loading engineering context throughout the AI-First engineering ecosystem.*



*All future retrieval engines, semantic search systems, vector databases, AI orchestration platforms, memory systems, repository intelligence services, and engineering assistants shall comply with this standard.*
