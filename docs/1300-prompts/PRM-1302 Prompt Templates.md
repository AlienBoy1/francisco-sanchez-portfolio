*# 1. Purpose*



*This document defines the official prompt template library for the Francisco Sánchez Portfolio AI-First engineering ecosystem.*



*The objective is to standardize prompt creation through reusable templates that ensure consistency, maintainability, governance, and engineering quality across all AI interactions.*



*Every production prompt shall originate from an approved template or a documented extension of one.*



*---*



*# 2. Objectives*



*The Prompt Templates library aims to:*



*- Standardize prompt creation.*

*- Improve engineering consistency.*

*- Accelerate prompt development.*

*- Promote prompt reuse.*

*- Reduce duplication.*

*- Improve maintainability.*

*- Simplify validation.*

*- Support scalable prompt engineering.*



*---*



*# 3. Template Philosophy*



*Templates are engineering blueprints.*



*A template defines the common structure of a prompt without prescribing implementation-specific content.*



*Templates shall maximize reuse while allowing controlled specialization.*



*---*



*# 4. Engineering Principles*



*Every template shall be:*



*- Modular.*

*- Generic.*

*- Reusable.*

*- Extensible.*

*- Maintainable.*

*- Deterministic.*

*- Documented.*

*- Version controlled.*



*---*



*# 5. Template Categories*



*The ecosystem defines the following template categories.*



*## System Prompt Templates*



*Persistent behavioral configuration.*



*---*



*## Task Prompt Templates*



*Single engineering task execution.*



*---*



*## Workflow Prompt Templates*



*Multi-step engineering processes.*



*---*



*## Validation Prompt Templates*



*Engineering review and verification.*



*---*



*## Documentation Prompt Templates*



*Documentation generation and maintenance.*



*---*



*## Agent Prompt Templates*



*Specialized AI Agent execution.*



*---*



*## Orchestration Prompt Templates*



*Multi-agent coordination.*



*---*



*## Utility Prompt Templates*



*Reusable operational activities.*



*---*



*# 6. Standard Prompt Template*



*The default production template shall follow this structure.*



*```text*

*Metadata*



*Objective*



*Role*



*Context*



*Inputs*



*Constraints*



*Process*



*Expected Output*



*Validation Criteria*



*Failure Conditions*

*```*



*This template shall serve as the baseline for production prompts.*



*---*



*# 7. Task Prompt Template*



*Task prompts shall include:*



*- Engineering objective.*

*- Required inputs.*

*- Constraints.*

*- Execution steps.*

*- Expected deliverables.*

*- Validation rules.*



*Task prompts shall remain narrowly focused.*



*---*



*# 8. Documentation Prompt Template*



*Documentation prompts shall include:*



*- Document identifier.*

*- Target audience.*

*- Documentation standard.*

*- Required sections.*

*- Formatting requirements.*

*- Validation checklist.*



*Generated documentation shall comply with governance standards.*



*---*



*# 9. Validation Prompt Template*



*Validation prompts shall define:*



*- Review scope.*

*- Validation criteria.*

*- Compliance checklist.*

*- Quality expectations.*

*- Improvement recommendations.*



*Validation prompts shall never modify artifacts directly unless explicitly authorized.*



*---*



*# 10. Workflow Prompt Template*



*Workflow prompts shall include:*



*- Workflow objective.*

*- Ordered activities.*

*- Decision points.*

*- Dependencies.*

*- Expected outcomes.*

*- Completion criteria.*



*Workflow prompts coordinate multiple tasks.*



*---*



*# 11. Agent Prompt Template*



*Agent prompts shall define:*



*- Agent role.*

*- Responsibilities.*

*- Scope.*

*- Context sources.*

*- Constraints.*

*- Success criteria.*



*Agent prompts shall align with the AI Agent architecture.*



*---*



*# 12. Orchestration Prompt Template*



*Orchestration prompts shall specify:*



*- Participating agents.*

*- Collaboration workflow.*

*- Context distribution.*

*- Responsibility allocation.*

*- Integration strategy.*

*- Validation process.*



*These templates govern multi-agent execution.*



*---*



*# 13. Template Versioning*



*Templates shall follow Semantic Versioning.*



*Major versions represent structural changes.*



*Minor versions introduce compatible improvements.*



*Patch versions correct defects.*



*Previous versions shall remain available for traceability.*



*---*



*# 14. Template Reuse*



*Templates shall be reused whenever applicable.*



*Specialized prompts shall inherit from existing templates instead of duplicating structure.*



*Template inheritance is preferred over template duplication.*



*---*



*# 15. Template Maintenance*



*Template reviews shall evaluate:*



*- Relevance.*

*- Reusability.*

*- Maintainability.*

*- Architectural consistency.*

*- Governance compliance.*



*Obsolete templates shall be deprecated through the governance process.*



*---*



*# 16. AI Operational Contract*



*## Responsibilities*



*Every AI Agent shall:*



*- Use approved templates.*

*- Preserve template integrity.*

*- Recommend template improvements.*

*- Maintain compatibility.*

*- Respect template versioning.*



*---*



*## Authorized Actions*



*Agents may:*



*- Instantiate templates.*

*- Extend templates.*

*- Recommend new templates.*

*- Improve template documentation.*

*- Suggest reusable modules.*



*---*



*## Restricted Actions*



*Agents shall not:*



*- Create production prompts without an approved template.*

*- Modify approved templates autonomously.*

*- Duplicate template structures unnecessarily.*

*- Bypass template governance.*

*- Use deprecated templates in production.*



*---*



*## Success Criteria*



*The Prompt Template library is successful when:*



*- Prompt creation becomes faster.*

*- Reuse increases.*

*- Engineering consistency improves.*

*- Maintenance effort decreases.*

*- Prompt quality becomes predictable.*



*---*



*## Failure Conditions*



*The Prompt Template library fails when:*



*- Templates proliferate without governance.*

*- Prompt duplication increases.*

*- Template quality degrades.*

*- Reuse declines.*

*- Template versioning is ignored.*



*---*



*## Escalation*



*Template changes affecting engineering standards or architectural consistency shall be approved by the Project Owner before adoption.*



*---*



*# 17. Governance*



*The Prompt Template library governs the creation of all production prompts within the AI-First engineering ecosystem.*



*Future prompt repositories, template registries, prompt generators and AI development platforms shall remain compatible with this standard.*
