*# Overview*



*The Francisco Sánchez Portfolio is not intended to be a traditional personal website.*



*It is designed as an engineering platform that demonstrates software development practices, architecture, documentation quality, design systems, accessibility, performance optimization, and modern frontend engineering.*



*The project serves as both a professional portfolio and a long-term platform capable of evolving alongside my career.*



*---*



*# Project Objectives*



*- Showcase real-world software engineering experience.*

*- Demonstrate modern frontend architecture.*

*- Present production-oriented projects.*

*- Document engineering decisions.*

*- Maintain enterprise-level documentation.*

*- Build a long-term professional platform.*

*- Follow modern accessibility standards.*

*- Achieve outstanding SEO and performance metrics.*
